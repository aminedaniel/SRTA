# Roadmap

## Milestone 1 — Research foundation

- Canonical company, feature, signal, and thesis models
- Plugin registry
- Small/mid-cap technology universe policy
- Composite research score
- CLI evaluation path
- Unit tests and CI

## Milestone 2 — Core financial evidence

- SEC XBRL ingestion
- Historical financial normalization
- Revenue, margin, cash-flow, dilution, and balance-sheet features
- Historical and peer valuation features
- Estimate-revision adapter interface
- Reverse-DCF scenario model

## Milestone 3 — Underappreciated evidence

- Form 4 cluster-buying parser
- House and Senate periodic-transaction disclosure adapters
- Congressional purchase aggregation with disclosure-lag controls
- GitHub and package-ecosystem activity
- Hiring and organizational-change signals
- Reddit awareness, sentiment, narrative, and manipulation filters
- Product-review and web-interest adapters

## Milestone 4 — Research workflow

- Ranked discovery screen
- Company research report
- Persistent thesis records
- Invalidation and catalyst tracking
- Weekly watchlist change report

## Milestone 5 — Validation

- Point-in-time datasets
- One-, two-, and three-year forward-return studies
- Value-trap and permanent-impairment analysis
- Signal ablation and combination analysis
- Sector and market-regime robustness
